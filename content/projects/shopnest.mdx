## Overview

ShopNest is a headless e-commerce storefront with a matching admin dashboard —
built for a boutique brand that had outgrown its template-based shop.

## My role

Full-stack developer: storefront, checkout, admin panel and the integrations with
payments and fulfilment.

## Highlights

- **Checkout in under a minute** — address autocomplete, saved payment methods and
  a single-page flow that lifted conversion noticeably.
- **Inventory sync** with the warehouse system every five minutes, with alerts for
  low stock.
- **Editorial content** (lookbooks, guides) managed from the same admin as products.
- **Image pipeline** that generates responsive variants on upload.

## Stack

React, Node.js (Express), PostgreSQL, Redis for sessions and caching, Stripe for
payments, deployed on AWS.

## Outcome

Page load times dropped by half compared with the previous shop and the client can
now launch a collection without developer help.
