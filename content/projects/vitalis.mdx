## Overview

Vitalis is a mobile app for tracking workouts, sleep and nutrition with a focus on
clear daily goals rather than endless charts.

## My role

Mobile developer and API designer on a team of three.

## Highlights

- **Daily goal ring** that summarises activity, sleep and nutrition into one number
  people actually look at.
- **Offline-first** logging — entries sync when the connection returns.
- **Health integrations** with Apple Health and Google Fit.
- **Privacy by default**: data stays on the device unless the user opts into sync.

## Stack

React Native with TypeScript, GraphQL API on Node.js, PostgreSQL, hosted on AWS
with push notifications via SNS.

## Outcome

Four-and-a-half-star rating across both app stores and a 40% day-30 retention in
the first cohort.
